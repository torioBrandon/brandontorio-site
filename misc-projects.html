Misc Project Highlights

Projects that don't fit neatly into video, photo, or marketing.

Cognitive neuroscience: Brainiak simulated dataset exercise

I volunteered with UT's LewPea Lab to test Brainiak, Intel's open-source Python package for analyzing brain imaging data, including comparing LSS functions.

  • Learned NumPy, denoised data, and read and interpreted voxel-wise fMRI data
  • Made videos explaining lab members' research — one won first place at the Texas Student Research Showdown (read about it)

Environ: video game tutorial interface

Environ is an educational game about environmental preservation. As part of the SAGA Lab at UT, I built its interactive tutorial interface.

  • Built the interface in Unity 3D using the provided creative design
  • Wrote JavaScript to control its behavior as players progressed
